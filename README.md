Installation & Usage
Requirements

Chrome or Edge browser

Microphone-enabled device

Internet connection

Steps

Clone or download the project:

git clone https://github.com/yourusername/amharic-speech-to-text.git


Open index.html in your browser

Click Start Recording and speak Amharic clearly

🔐 Privacy & Security

No audio data is stored

All processing happens inside the browser

Microphone access is requested only when recording starts

⚠️ Limitations

Requires internet connection

Works best in Chrome-based browsers

Accuracy decreases in noisy environments

Firefox and Safari may not fully support the Speech API
